# Design changelog

Dated design changes and reversals, newest first. Current intended behavior lives in DESIGN.md; rationale and approval live in DECISIONS.md. Link those records rather than copying their full contents. Git history preserves earlier snapshots. Do not log routine implementation work, every tuning adjustment or test runs here unless they change an intended rule or an experiment's scope/status.

For an authorized design change, update the current design and append an entry in the same reviewed change. Preserve previous entries and mark superseded decisions explicitly. Recording a proposal does not authorize implementation.
